# Utility Bill Management System

A C# Windows Forms application for recording meter readings, generating monthly
bills and tracking payments.

## Features

- Record customer meter readings
- Generate monthly utility bills automatically
- Track payment status (paid / unpaid)
- Crystal Reports for bills and revenue reports

## Tech Stack

- C# / .NET Windows Forms
- ADO.NET
- Microsoft SQL Server
- SAP Crystal Reports

## Setup

1. Clone the repository
2. Restore the database (script or backup in the `Database` folder, if you have one)
3. Update the connection string in `App.config`
4. Open the `.sln` in Visual Studio and press F5
